# 🌸 회귀한 MD가 K뷰티 전설이 되다

망한 화장품 브랜드 대표가 10년 전 창업 첫날로 회귀했다.
원룸 사무실에서 시작해 국내 1위 K뷰티 브랜드를 키우는 도트 경영 시뮬레이션 게임.

▶ **플레이:** https://backyu100-lgtm.github.io/kbeauty-legend/

## 특징
- 직원 채용·면접·육성 (대기만성 / 월급루팡 숨은 기질)
- 신제품 기획부터 출시, 광고, 플랫폼 빅세일까지
- 플랫폼 입점 심사, 사무실 10단계, 자체 공장 증설
- 회귀 기억으로 내년 트렌드 예지
- 모바일 지원, 진행 상황은 브라우저에 자동 저장
